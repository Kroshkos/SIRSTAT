## 🚀 Как начать работать

### Для тестирования и bug reports

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Kroshkos/SIRSTAT.git
   cd SIRSTAT
   pip install -r requirements.txt
   python 1.py
   ```

2. При обнаружении бага создайте Issue с:
   - Версией программы
   - Системой и ОС (Windows/macOS/Linux, версия)
   - Фрагментом журнала с ошибкой
   - Обезличенным примером входного файла (если возможно)

### Для разработки функций

1. Ветка для вашей задачи:
   ```bash
   git checkout main && git pull
   git feature/новая_функция
   ```

2. Создайте ветку и внесите изменения:
   - Напишите код в соответствующем модуле (`app_core.py`, `sheet_builder.py` и т.д.)
   - Добавьте тесты (опционально, но рекомендуется)
   - Обновите документацию при необходимости

3. Откройте Pull Request с описанием изменений:
   - Что делает новая функция/исправление?
   - Как это использовать?
   - Есть ли совместимость с существующими данными?

## 📚 Правила вклада

### ⚖️ Лицензия и права

- SIRSTAT распространяется по **проприетарной некоммерческой лицензии** v1.0
- Коммерческое использование требует письменного разрешения автора
- Все изменения должны сохранять уведомления об авторстве
- Исходный код интеллектуальная собственность автора

### 📝 Стиль кода

- Используйте `black` или аналогичный форматтер для Python
- Добавляйте комментарии к сложным секциям кода
- Следуйте существующей структуре модулей (`app_core.py`, `sheet_builder.py`)

### 📖 Документация

- Обновляйте README.md при добавлении новых функций
- Добавьте примеры использования в отдельный раздел
- Переводите разделы на другие языки (рус/укр)

## 🧪 Тестирование и CI/CD

### Локальное тестирование

```bash
# Установка зависимостей
pip install -r requirements.txt pytest

# Запуск тестов (если есть)
pytest tests/

# Сборка для проверки
pyinstaller build.spec --noconfirm
```

### GitHub Actions

При наличии теста в Pull Request workflow автоматически:
- Соберёт `.exe` и `.app`
- Проведет smoke-test (import modules)
- Проверит на отсутствие критических ошибок
