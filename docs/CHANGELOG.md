# 📜 Чangelog SIRSTAT

История версий, исправлений и улучшений программы SIRSTAT — анализ антибиотикорезистентности и эпидемиологии посевов.

---

## [v1.0] — 22 октября 2026

### 🎉 Первый релиз!

#### ✨ Возможности
- Современный интерфейс на CustomTkinter (тёмная/светлая тема)
- Автоопределение структуры входных файлов (.xls/.xlsx)
- Поддержка нескольких клиник с режимом сравнения
- Конструктор пользовательских листов с группировкой и фильтрами
- Экспорт в Excel (.xlsx) и PDF для руководства
- Визуализация через диаграммы и heatmap

#### 🛠 Технические детали
- Python 3.10+ (рекомендуется 3.11)
- Платформы: Windows, macOS, Linux
- Сборка через PyInstaller (one-dir для быстрого запуска)
- Оптимизированные excludes в `build.spec`

#### 📄 Документация
- [`README.md`](../README.md): полное руководство пользователя
- [`RELEASE.md`](../RELEASE.md): инструкция по сборке релизов
- [`SIGNING.md`](../SIGNING.md): настройка кодовой подписи Windows/macOS
- [`LICENSE`](../LICENSE): проприетарная некоммерческая лицензия v1.0

## [v1.1] — 23 ноября 2026

### 🔧 Исправления и улучшения

#### 🐛 Исправления (Bug Fixes)
- Исправлено: наложение donut/баров в PDF-отчёте (разнесены 0.045+0.26 vs 0.48+0.48)
- Исправлено: длинные названия микробов/антибиотиков выходят за левый край (left=0.22)
- Исправлено: защита от `AttributeError: 'str' object has no attribute 'size'` через `_to_series()`
- Обновлен: ffill().bfill() вместо fillna(method=...) для надёжности

#### 🎨 Улучшения (Improvements)
- Обновлен интерфейс с карточками и цветными метками в журнале обработки
- Добавлена строка состояния с прогрессом обработки
- Фоновая обработка — окно не «замерзает» при больших данных

#### 📚 Документация
- Обновлён `README.md` с полной структурой отчёта и FAQ
- Обновлён `RELEASE.md` с инструкциями по локальной сборке и подписи
- Обновлён `SIGNING.md` с подробным описанием настройки код-сайнинга

#### 🧪 Под капотом (Under the Hood)
- Обновлены требования: pandas>=2.0, numpy>=1.24, openpyxl>=3.1, customtkinter>=5.2
- Добавлен `xlrd` для чтения старых `.xls` файлов в сборке
