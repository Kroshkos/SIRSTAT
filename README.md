## 📌 Быстрый старт

### Вариант А: Готовая сборка (рекомендуется)

1. Скачайте последнюю версию с [Releases](https://github.com/Kroshkos/SIRSTAT/releases)
2. Распакуйте ZIP-архив
3. Запустите `SIRSTAT.exe` (Windows) или перетащите `SIRSTAT.app` в Dock (macOS)
4. Откройте входной файл `.xls` или `.xlsx` — программа сама определит структуру

### Вариант Б: Установка из исходников

```bash
git clone https://github.com/Kroshkos/SIRSTAT.git
cd SIRSTAT
pip install -r requirements.txt
python 1.py
```

## ✨ Возможности

- **Современный интерфейс** на CustomTkinter: тёмная/светлая тема, карточки, прогресс-бар, журнал обработки с цветными метками
- **Автоопределение структуры файла**: программа сама находит лист с данными, строку заголовков и блок антибиотиков
- **Автоопределение клиник** (столбец «Клиника» или первый столбец-разделитель) с числом посевов каждой
- **Три режима работы**: конкретная клиника, «Все клиники», «⚖️ Сравнение клиник»
- **Конструктор листов** — неограниченное число дополнительных листов отчёта с группировкой по любому сочетанию полей и фильтрами
- **Диаграммы сравнения** — столбчатые графики S% по микроорганизмам для каждой клиники

## 📋 Формат входных данных

Программа распознаёт следующие поля (синонимы):

| Поле | Ключевые слова |
|------|----------------|
| **Микроорганизм** | микро, organism, возбудитель, специес, species |
| **Дата** | дат, date, число, дата посева, поступил |
| **Материал** | матер, биоматеріал, локализ, object, bid, вид материала |
| **Пациент** | история, patient, номер, карта, закз, id, №, фио, fio |
| **Клиника** | clinic, ВМХ/ВПХ/ГХ или любой разделитель |

Жёсткой структуры данных не требуется — программа сама находит нужные поля. Поддерживаются `.xls` и `.xlsx`.

---

## 📊 Что внутри отчёта?

1. **Анализ посевов** — таблица всех изолятов с детализацией
2. **Эпидемиология** — сводная статистика частоты выделения возбудителей (%)
3. **Антибиотикорезистентность** — матрица S% + heatmap для визуализации
4. **Дополнительные листы** — через конструктор: группировка, метрики, антибиотикограмма по антибиотику

## ❓ FAQ

**Что, если файл не распознаётся?**  
Убедитесь, что в файле есть таблица с колонками: дата, материал, микроорганизм.

**Можно ли добавить свои поля?**  
Да! Конструктор поддерживает любое количество дополнительных полей.

**Как сравнить два периода?**  
Выгрузите оба периода в один файл и добавьте колонку-разделитель для группировки.

**Какие версии Python поддерживаются?**  
Python 3.10+ (рекомендуется 3.11).

**Можно ли использовать в коммерческих целях?**  
См. раздел [Лицензия](LICENSE) — некоммерческое использование бесплатно.
