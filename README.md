## ✨ Возможности

### 🎨 Современный интерфейс
- **CustomTkinter**: тёмная/светлая тема, карточки, прогресс-бар
- **Журнал обработки** с цветными метками статуса
- **Фоновая обработка** — окно не «замерзает» при больших данных

### 📊 Автоопределение структуры файла
- Самостоятельное обнаружение листа с данными (TDSheet или первый лист)
- Автоматическое определение строки заголовков
- Распознавание блока антибиотиков без жёстких требований к оформлению

### 🏥 Управление клиниками
- **Автоопределение клиник** через столбец «Клиника» или разделители (ВМХ/ВПХ/ГХ)
- **Три режима работы**:
  - ✅ Конкретная клиника — отчёт только по её данным
  - ✅ «Все клиники» — отдельный файл для каждой клиники (`отчёт — ВМХ.xlsx`, `отчёт — ВПХ.xlsx`...)
  - ⚖️ **«Сравнение клиник»** — сравнительные диаграммы чувствительности

### 🔬 Конструктор пользовательских листов
- Неограниченное количество дополнительных аналитических листов
- **Группировка** по: микроорганизм, материал, категория, год/месяц/неделя/квартал, пациент и т.д.
- **Метрики**: частота выделения (выражаемость), доля резистентных, доля чувствительных, доля промежуточных
- **Антибиотикограммы**: суммарная или по отдельным антибиотикам
- **Фильтры и пресеты** в JSON для сохранения настроек
- Режим сравнения клиник также доступен внутри конструктора

### 📈 Визуализация данных
- **Диаграммы сравнения**: столбчатые графики S% по микроорганизмам
- **Тепловые карты** (heatmaps) для антибиотикограмм
- **Donut/бар диаграммы** для эпидемиологического анализа

### 📄 Экспорт отчётов
- **Excel (.xlsx)**: базовые листы + пользовательские + диаграммы
- **PDF**: профессиональный отчёт для руководства с фирменной стилистикой

## 📋 Формат входных данных

### Распознаваемые столбцы (синонимы)

| Поле | Ключевые слова (рус/англ) |
|------|---------------------------|
| **Микроорганизм** | `микро`, `organism`, `возбудитель`, `специес`, `species` |
| **Дата** | `дат`, `date`, `число`, `дата посева`, `поступил` |
| **Материал** | `матер`, `биоматеріал`, `локализ`, `object`, `bid`, `вид материала` |
| **Пациент** | `история`, `patient`, `номер`, `карта`, `закз`, `id`, `№`, `фио`, `fio` |
| **Клиника** | `clinic`, любой разделитель (ВМХ, ВПХ, ГХ и т.д.) |

### Пример структуры входного файла

| Клиника | Микроорганизм | Материал | Дата посева | Антибиотик-1 | R/S/I | ... |
|---------|---------------|---------|-------------|--------------|-------|-----|
| ВМХ     | E. coli       | Моча    | 2024-01-15  | Ампициллин   | R     | ... |
| ВПХ     | K. pneumoniae | Кровь   | 2024-01-16  | Цефтриаксон  | S     | ... |

**Важно**: 
- Жёсткая структура **не требуется** — программа сама находит нужные поля
- Антибиотики могут быть в отдельных столбцах или в едином поле (разделителем, например `;`)
- Поддерживаются старые `.xls` и современные `.xlsx` файлы

## 📊 Что внутри отчёта?

### Базовые листы (всегда создаются)

1. **Анализ посевов** — таблица всех изолятов с детализацией по микроорганизму, материалу, клинике
2. **Эпидемиология** — сводная статистика частоты выделения возбудителей (%)
3. **Антибиотикорезистентность** — матрица S% (доля чувствительных) + heatmap для визуализации

### Дополнительные листы (через конструктор)

- Группировка по: микроорганизм / материал / категория / время / пациент
- Метрики: частота, доля резистентных, доля чувствительных
- Антибиотикограмма: суммарная или по конкретному антибиотику
- Диаграммы и графики по желанию

---

## 🧮 Методика расчётов

### Частота выделения (выражаемость)
```
Частота (%) = (Количество изолятов вида / Общее число изолятов) × 100
```

### Доля резистентных/чувствительных/промежуточных (S/I/R)
```
S% (чувствительные)    = S / (S + I + R) × 100
R% (резистентные)      = R / (S + I + R) × 100
I% (промежуточные)     = I / (S + I + R) × 100
```

### Матричная антибиотикограмма (S-индекс)
```
S% для микроба/антибиотика = 
    Количество чувствительных строк этого микроба
    ------------------------------------------ 
    Общее число строк этого микроба × 100
```

**Важно**: расчёты соответствуют CLSI/EUCAST рекомендациям

## 🔌 Использование без GUI (API ядра)

Для программной интеграции используйте модуль `app_core.py`:

```python
from app_core import run_pipeline, load_data, detect_clinics

# Загрузка данных
df, _, data, log, _ = load_data('input_file.xlsx')

# Обработка и сохранение Excel-отчёта
run_pipeline(
    data=data,
    output_file='report.xlsx',
    clinic_name='Все клиники'  # или конкретная клиника: 'ВМХ'
)

# Сравнение клиник
run_clinic_comparison(
    data=data,
    clinics=['ВМХ', 'ВПХ'],
    output_file='comparison.xlsx'
)
```

### Доступные функции ядра

| Функция | Описание |
|---------|----------|
| `load_data()` | Загрузка и предобработка из Excel |
| `detect_clinics()` | Определение списка клиник в файле |
| `run_pipeline()` | Генерация базового отчёта (Excel) |
| `run_pipeline_multi_clinic()` | Отдельные файлы для каждой клиники |
| `run_clinic_comparison()` | Сравнительная матрица для выбранных клиник |
| `get_file_info()` | Получение информации о файле перед загрузкой |
| `count_rows_by_clinic()` | Подсчёт посевов по клиникам |

## ❓ Частые вопросы (FAQ)

### Что, если файл не распознаётся?
Убедитесь, что в файле есть таблица с колонками: дата, материал, микроорганизм или похожими названиями. Программа ищет ключевые слова (см. раздел «Формат входных данных»).

### Можно ли добавить свои поля в конструктор?
Да! Конструктор поддерживает любое количество дополнительных полей для группировки.

### Как сравнить два периода времени?
Выгрузите оба периода в один файл с колонкой, различающей периоды, добавьте её как поле группировки (год/месяц/неделя/квартал) или используйте фильтры пресетов.

### Как работает режим «Сравнение клиник»?
Выберите нужные клиники — программа создаст диаграммы сравнения чувствительности по матрице S% для каждого микроорганизма и антибиотика.

### Какие версии Python поддерживаются?
Python 3.10+ (рекомендуется 3.11 или новее). CI использует 3.11 для сборки.
